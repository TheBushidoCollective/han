# Kanban

Kanban task and dependency management for AI coding agents using the YYLO Ledger CLI.

## Skills

- **kanban-task-management**: Retrieve any YYLO Ledger Record by ID, discover PDRs and artifacts, and manage tasks and dependencies — universal get/search, task operations, and source-of-truth boundaries.

## Installation

Install with the han CLI:

```bash
han plugin install kanban
```
